## 回归修复：评论列表首屏为空
现象：首次进稿件页/打开二级评论弹窗，评论列表空，点排序 tab 才出来。
根因：重构时删掉了 VideoComment / SecondComment 里 created() 的首次拉取，而 useCommentList 当时没有 immediate
自动加载（usePagination / useTable 都有，唯独它漏了）。
修复：useCommentList 增加 immediate 选项（默认 true），用 watch(() => resolveArticleId(), v => v && load(1),
{ immediate: true }) 在拿到有效稿件 id 时拉第一页；用 watch 是为了兼容路由参数异步就绪，避免 article=0 的无效请求。

经验：抽 composable 时必须把原组件 created/mounted 里的「首次加载」语义一并搬进去。
