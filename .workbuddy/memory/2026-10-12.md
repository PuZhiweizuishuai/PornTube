## 后续修复：改动引入的两个回归（用户反馈）

1. **全站图标不显示（只剩空白圆圈）**：把 vuetify 相关 import 抽到 `src/plugins/vuetify.js` 时，
   漏掉了 `import '@mdi/font/css/materialdesignicons.css'`。`icons.defaultSet='mdi'` 只负责
   生成 `mdi-xxx` 类名，字形靠这个 CSS，缺了就只剩 v-btn 的 ripple 圆圈。
   已补回 `plugins/vuetify.js`。**教训：搬移 import 时逐条比对，不要用「重写」代替「移动」。**
2. **侧栏「首页」永远高亮**：导航项从 `:href` 改成 `:to` 后，Vuetify `useLink` 默认走
   vue-router 的 `isActive`（前缀匹配），`to="/"` 能匹配所有路径 → 永远激活。
   解法：AppSidebar 自己算 `activePath`，`/` 只做精确匹配，其余 `path===to || startsWith(to+'/')`，
   并且**只取最长匹配项**，保证任何时刻最多一个条目高亮；再用 `:active="item.to === activePath"`
   显式传给 v-list-item（VListItem 里 `props.active === false` 会完全压制内部判定）。

## 侧栏收起（rail）态优化

- **图标缺文字提示**：Vuetify 的 rail 模式**不会**自动给图标加 tooltip（VNavigationDrawer 在 rail 下
  只 provide 了 `VList: { bgColor: 'transparent' }`，VListItem 的 sass 里 rail 只缩小 `.v-avatar`）。
  自己在 AppSidebar 里用 `v-tooltip` 包住 `v-list-item`，`:disabled="!isRail"` 只在收起时启用，
  `location="end"` 让提示出现在右侧；同时收起时把 `:title` 置空，避免出现被截断的半截文字。
  `VTooltip` 的 `disabled` 来自 `makeVOverlayProps`，可用。
- **收起后底部信息挤成一团**：底部版权/反馈改成 `<template v-if="!isRail" #append>`。
  已用 @vue/compiler-sfc 验证：具名插槽上的 v-if 会编译成 `createSlots` 的条件条目，
  条件为假时 `slots.append` 就是 `undefined`，VNavigationDrawer 的 `slots.append && ...`
  因此完全不渲染 append 容器，**不会留下空 div / 内边距**。
- 顶部用户信息块在收起时同样只保留头像并居中。

## 踩坑 / 环境备注
- 直接 `npm run build` 会失败：Vite 要清空 `dist/`（386 个旧产物），触发批量删除保护。
  验证构建请用 `--outDir dist/.verify`（dist 已被 .gitignore，不污染 git status）。
- 项目根 `TikTubeWeb/` 下遗留一个 `dist-verify/`（约 111 文件 / 8.3M）是我第一次验证构建的产物，
  **删除和移动都被回收站/权限拦住了**，需要用户手动删除。
- curl 本地 dev server 要走 `--noproxy '*'` 且用 `localhost`，否则被代理挡成 502。
